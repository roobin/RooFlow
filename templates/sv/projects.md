# Projekt

State bestämmer var ett projekt syns i överblicken: **now** och **next** är aktiva, **waiting** väntar på någon,
**parked** vilar och kan väckas. Ett streck (eller tom State) betyder att projektet inte visas. De svenska orden
nu, nästa, väntar och parkerat fungerar också. Kolumnrubrikerna är engelska, skripten läser dem.

Kortnamnet (slug) som agenter och statusfiler använder är mappnamnet med gemener.
